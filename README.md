# Trailer Lab

**צלמו. ערכו. תהיו הבמאים.**

האפליקציה שהופכת כל ילד וילדה לקולנוען אמיתי: מצלמים בטלפון לפי סוגי שוטים מקצועיים, ומקבלים טריילר קולנועי עם כותרות, מוזיקה וקרדיטים.

**האפליקציה:** https://gzfilm.github.io/trailer-lab/

- בוחרים ז׳אנר: אקשן, אימה, מרדף, מותחן, הרפתקה, מדע בדיוני, פנטזיה, מערבון, קומדיה, דרמה וספורט.
- מצלמים כל שוט 5 שניות לפי רשימת שוטים של במאי, עם קווי מסגור על המסך.
- האפליקציה בוחרת את הרגע הכי חזק בכל שוט, מוסיפה כותרות, מוזיקה וקרדיטים, ומייצאת MP4.
- פוסטר ותמונה ממוזערת לסרט, ושמירת פרויקטים כדי להמשיך בפעם הבאה.

**פרטיות:** הכול נשמר רק במכשיר עצמו. הסרטונים והשמות לא נשלחים לשום מקום.
